mapcn-react-native is a registry of map components for Expo and React Native. It gives you a renderer-independent component API while letting you choose MapLibre or Mapbox underneath.

## You own the code

mapcn-rn follows the shadcn model: the CLI copies component source into your application. There is no mapcn runtime package between your app and the native renderer. You can read the implementation, change it, and commit it with the rest of your code.

That ownership has a tradeoff. Upgrades are source updates, not opaque package bumps. `mapcn-rn diff` shows how an installed component differs from its registry version, and an overwrite creates a backup before replacing a locally changed file.

## What v2 provides

- One shared API across MapLibre and Mapbox, with explicit capability notes where the native SDKs differ.
- Basemap providers selected separately from the renderer: CARTO, MapTiler, custom styles, or Mapbox.
- Composable components for maps, markers, popups, controls, routes, GeoJSON, clustering, location, styling, and thematic maps.
- A project-local `mapcn.json` that records the renderer, provider, styling system, aliases, installed versions, and file hashes.
- CLI checks for native dependencies, Expo plugins, provider credentials, permissions, and local component changes.

## When to use it

Use mapcn-rn when you want a native vector map, a component API you can customize in your repository, and the option to choose between MapLibre and Mapbox without rewriting higher-level map features.

## When not to use it

It is probably not the right fit when:

- you need maps to run in Expo Go; both native renderers require a custom development build;
- you want a hosted, zero-code map rather than source files owned by your application;
- you need background location tracking today—the v2 location component is foreground-only;
- you need every renderer-specific feature to behave identically. mapcn-rn exposes capability differences instead of faking parity;
- you are building for the web only. These components target React Native native map SDKs.
