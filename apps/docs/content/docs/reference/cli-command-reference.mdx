```text
mapcn-rn init [--renderer maplibre|mapbox] [--provider maptiler|carto|custom|mapbox] [--all] [--components a,b] [--yes]
mapcn-rn add <component...> | --all [--overwrite] [--yes] [--renderer maplibre|mapbox]
mapcn-rn list
mapcn-rn diff [component]
mapcn-rn doctor [--json] [--verbose]
mapcn-rn provider <target> [--yes] [--force]
mapcn-rn migrate [--yes]
mapcn-rn --help
```

| Command | Purpose | Detail page |
| --- | --- | --- |
| `init` | Set up renderer, provider, `mapcn.json`, native config, and the components you pick. | [init](/docs/cli/init) |
| `add` | Install one or more registry components (or `--all`), resolving dependencies. Runs `init` first if the project has none. | [add](/docs/cli/add) |
| `list` | Show every registry component and what's installed. | [list & diff](/docs/cli/list-and-diff) |
| `diff` | Compare installed files against their recorded hashes. | [list & diff](/docs/cli/list-and-diff) |
| `doctor` | Run 14 non-mutating project health checks. | [doctor](/docs/cli/doctor) |
| `provider` | Switch renderer and/or basemap provider, rewriting only adapter files. | [provider](/docs/cli/provider) |
| `migrate` | Assisted v1 → v2 upgrade. | [migrate](/docs/cli/migrate) |

## Global options

| Option | Description |
| --- | --- |
| `--registry <url>` | Override the registry base URL (default `https://mapcn-rn.dev/r`). Accepts an `https://` URL, a local directory, or a `file://` path. |
| `-h`, `--help` | Show the command help text. |
